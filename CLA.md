## How to sign

Add a `Signed-off-by` line to your commits stating that you have read and agree
to this Agreement:

```
git commit -s -m "your message"
```

The `-s` flag appends:

```
Signed-off-by: Your Name <your@email.example>
```

By adding that line to a commit that contains a Contribution, You certify that
You have read this Agreement and agree to its terms for that Contribution.

If You are contributing on behalf of a company, have someone authorized to bind
the company open an issue titled "Corporate CLA" before your first pull request.
