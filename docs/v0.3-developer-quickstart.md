# ClawMe v0.3 本地开发快速开始

这条链路已经可运行：

```text
Codex app-server（客户电脑）
  ↕ 原生 JSON-RPC
ClawMe Agent（客户电脑）
  ↕ HTTPS / 主动出站
ClawMe Relay（api.clawme.net 或自建）
  ↕ HTTPS
ClawMe 手机值班台（PWA）
```

## 1. 启动 Relay

```powershell
cd backend
npm install
npm run build
$env:CLAWME_TOKENS="dev-token"
npm start
```

开发环境可不设置 `CLAWME_TOKENS`，生产环境必须设置。任务、待办和手机决定默认保存在
`backend/data/clawme-v3.json`，也可用 `CLAWME_DATA_FILE` 改路径。

## 2. 启动手机值班台

把 `web/` 作为静态网站运行，打开 `/app.html`，填写：

- Relay 地址：本地开发为 `http://电脑IP:31871`，正式版为 `https://api.clawme.net`
- 配对 Token：与 Relay 中配置的一致

第一版用 PWA，验证需求和交互；原生 iOS/Android App 在推送、商店分发和设备能力确有需要时再做。

## 3. 在电脑启动原生 Codex 任务

```powershell
cd agent
$env:CLAWME_BASE_URL="http://127.0.0.1:31871"
$env:CLAWME_TOKEN="dev-token"
$env:CLAWME_CWD="C:\path\to\project"
npm start -- run "检查项目，运行测试并修复失败"
```

ClawMe Agent 会启动 Codex 官方 `app-server`，而不是模拟终端按键。Codex 请求执行命令或
修改文件时会保持等待；手机点“允许一次”或“拒绝”后，决定会返回原生授权请求。

## 4. 客户怎么使用

默认推荐“你的服务器托管 Relay”：

1. 客户安装 U‑Claw Agent。
2. 安装器生成设备配对码。
3. 客户手机打开 ClawMe PWA 扫码绑定。
4. 电脑主动连接 `api.clawme.net`，无需公网 IP、端口映射或远程桌面。
5. 代码、命令和模型凭证留在客户电脑；Relay 只保存必要的任务摘要与待处理事项。

企业或隐私敏感用户可以自建同一套 Relay，并在 Agent 中替换 `CLAWME_BASE_URL`。
